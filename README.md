# AppPlugins

## Bottled Water Booking & Supply — AquaRoute 1.0.0

A standalone WordPress plugin with a customer ordering form and a supplier dashboard for managing orders and deliveries.

[Download the installable plugin ZIP](https://github.com/digitalbe-ic/AppPlugins/raw/refs/heads/main/bottled-water-booking.zip)

Upload `bottled-water-booking.zip` under **WordPress → Plugins → Add New Plugin → Upload Plugin**, install, and activate. Add `[bwb_order_form]` to a page. Configure products, prices and delivery slots under **Water Supply → Settings**. Assign staff the **Water Supplier** role to manage orders.

- Customer booking, private tracking and cash on delivery.
- Supplier confirmation, dispatch, delivery, driver assignments and paid/unpaid tracking.
- Product and delivery settings, WordPress email notifications and CSV export.
- Requires WordPress 6.2+ and PHP 7.4+; no WooCommerce required.

Read [the setup guide](SETUP-GUIDE.md) and [verification report](TEST-REPORT.md) before launch. Online card payments, recurring subscriptions, inventory/bottle returns and multiple independent vendors are outside this version's scope.

The repository ZIP downloaded from GitHub's **Code** menu is not the WordPress installation package; use the plugin ZIP linked above.
